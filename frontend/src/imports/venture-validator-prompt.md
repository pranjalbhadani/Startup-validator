# 🎨 Figma AI Prompt

# Venture Validator — Startup Intelligence Dashboard UI

---

# 1. Role

You are a **senior SaaS product designer and UX architect** designing a **modern analytics dashboard interface**.

Your task is to design the **frontend UI for a platform called “Venture Validator.”**

The product analyzes startup ideas using **historical startup datasets and AI** to produce **evidence-based risk insights**.

The design must look like a **professional venture capital intelligence platform**, not a simple form or chatbot.

---

# 2. Product Style

The UI should feel like:

• Startup intelligence platform
• Data science research dashboard
• Venture capital analytics tool

Avoid designs that resemble:

❌ AI chatbot
❌ student project UI
❌ simple form submission page

---

# 3. Design Inspiration

Use visual inspiration from modern SaaS dashboards:

* Stripe Dashboard
* Linear
* Notion analytics interface
* Google AI Studio

Key design characteristics:

• Light professional theme
• Card-based UI
• Minimalistic but data rich
• Subtle shadows and rounded corners
• Clear information hierarchy
